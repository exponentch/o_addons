Partner Autocomplete Bulk

Enrich multiple contacts at once using Odoo's partner autocomplete service. Select partners from the list view, review exact name matches, and update their information in bulk. Only contacts with exact name matches are suggested — each enrichment consumes IAP credits from Odoo.

Key Features

Bulk autocomplete from the Contacts list view — select up to 80 partners at once
Exact name matching to avoid false positives and unnecessary credit usage
Preview & select which contacts to enrich before consuming credits
Auto-fills VAT, address, phone, company logo and more from official registries
Supports DUNS, GST, and domain-based enrichment methods
Automatic phone number formatting to international standard
Restricted to administrators only for controlled IAP credit usage

How it Works

1
Go to Contacts and switch to list view
2
Select the contacts you want to enrich (up to 80 at a time)
3
Click Actions → Bulk Autocomplete Partners
4
The system queries Odoo's autocomplete API for each contact name
5
A wizard shows all contacts with exact name matches
6
Uncheck any contacts you don't want to enrich
Click Autocomplete to enrich the selected contacts
Note: Each enriched contact consumes IAP credits from your Odoo account. Only contacts with exact name matches in Odoo's database are suggested.
